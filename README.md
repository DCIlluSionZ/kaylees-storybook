# Kaylee's Magical Storybook

A web-based, interactive "Choose Your Own Adventure" storybook app built for an 8-year-old. The backend is a tiny Node/Express service that calls the Gemini API; the frontend is plain HTML/CSS/JS with browser-native text-to-speech.

## How it works

1. The app shows a 40–60 word chunk of story and reads it aloud.
2. At the end of the chunk it offers **2–3 large, colorful choices** for what Kaylee does next.
3. Choices are **generated by the LLM**, not typed — the system prompt keeps them on-track inside the pre-loaded lore (Kaylee, Lucy the fairy, the ancient tree, the silver wand, pink wings, etc.).
4. Tapping a choice sends it back to the backend, which sends it on to Gemini with the running story history, and a new chunk + choices are returned in strict JSON.

The Gemini API key never leaves the server.

## Setup

```bash
# 1. Install dependencies
npm install

# 2. Create your .env from the template and paste your key in
cp .env.example .env
# then edit .env and set GEMINI_API_KEY=...

# 3. Run the server
npm start
```

Open <http://localhost:3000> and tap **Start the Adventure**.

## Environment variables

| Variable         | Required | Default            | Notes                                  |
|------------------|----------|--------------------|----------------------------------------|
| `GEMINI_API_KEY` | yes      | —                  | From Google AI Studio.                 |
| `GEMINI_MODEL`   | no       | `gemini-1.5-flash` | Use `gemini-1.5-pro` for higher quality. |
| `PORT`           | no       | `3000`             | Server port.                           |

## Hosting on DCI Cloud Hub

The app is a vanilla Node.js process and can run behind any reverse proxy (nginx, Caddy, Cloudflare Tunnel, etc.). Two things to remember:

1. Set `GEMINI_API_KEY` as an environment variable on the server (do **not** commit `.env`).
2. Make sure the host can reach `https://generativelanguage.googleapis.com`.

Run it with a process manager (pm2, systemd, Docker, etc.):

```bash
pm2 start server.js --name kaylees-storybook
```

## Safety design

The system prompt explicitly forbids violence, scary content, romance, real-world brands, requests for personal info, and any topic outside the storybook lore. Gemini's safety filters are also turned up to `BLOCK_LOW_AND_ABOVE` on all four harm categories. The server validates every response against a JSON schema before sending it to the frontend — malformed or unsafe responses are replaced with a friendly retry message.

## Endpoints

- `POST /api/story` — body: `{ choice?: string, history?: Array<{role, text}> }`. Returns `{ chunk, choices, scene }`.
- `GET /api/health` — returns `{ ok: true, model }`.
